# Raw-data directory

Place the cited public source ZIP archives here. The expected default filenames are listed in `../manifests/raw_file_map.json`.

Required inputs:

- OULAD public ZIP;
- South German Credit ZIP;
- Heart Disease ZIP;
- 2018 ACS 1-Year PUMS person ZIPs for California, Florida, New York, and Texas;
- 2024 ACS 1-Year PUMS person ZIPs for the same four states.

Raw source archives are intentionally excluded from Git.
