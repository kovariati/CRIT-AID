# Third-party data notice

The MIT License in this repository applies only to the original CRIT-AID software and documentation.

The following source datasets are not covered by the software license and remain subject to their source repository terms:

- Open University Learning Analytics Dataset (OULAD);
- South German Credit;
- UCI Heart Disease;
- U.S. Census Bureau ACS Public Use Microdata Sample (PUMS).

Raw source archives are not committed to the repository. The analysis code expects users to obtain the data from the repositories cited in the manuscript. Stable record keys, split manifests, source-file names, and SHA-256 records are supplied for auditability.

The GitHub Release asset contains analysis outputs and reproducibility metadata. It does not contain the original raw archives.
