# Machine-readable results

This directory contains the compact and medium-size result tables needed to audit the published claims without rerunning the full pipeline. Files with `complete`, `summary`, `bootstrap`, `tradeoff`, `variance`, or `sensitivity` in their names are intentionally retained because they support manuscript-level and diagnostic claims.

Three large generated files are distributed as a **GitHub Release asset** rather than committed to Git history:

- `acs_risk_selection_curves.csv.gz`
- `oulad_risk_selection_curves.csv.gz`
- `acs_primary_target_predictions.csv.gz`

They can be regenerated by the analysis pipeline and are not required for the source-only repository audit. To perform the complete results audit, extract the release asset so these files appear in this directory, then run:

```bash
python scripts/audit_repository.py --mode results
```
